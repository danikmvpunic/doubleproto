# Double · Pre-construction Site Intelligence

**MVP v0.1** — по координатам участка собирает отчёт по грунту, климату и предварительные рекомендации по фундаменту за минуту вместо месяца у геолога.

## Зачем

Частный заказчик ИЖС в Казахстане платит геологу 80–200 тыс. ₸ и ждёт 2–4 недели отчёт по грунту, чтобы выбрать фундамент. До этого момента стройка стоит. Double сокращает этот цикл до одного дня.

## Что делает v0.2

- Принимает координаты (lat, lon).
- Тянет климат за 365 дней (Open-Meteo Archive).
- Тянет рельеф (Open-Meteo Elevation) и адрес (OpenStreetMap Nominatim).
- Тянет состав грунта 0–30 см (SoilGrids v2.0).
- Считает нормативную глубину промерзания по СНиП 2.02.01-83.
- Определяет снеговую зону и расчётную нагрузку (СП РК).
- Генерирует markdown- или JSON-отчёт с рекомендациями и их обоснованием.

## Формулы и источники

- Глубина промерзания: d_f = d_0 · √M_t (СНиП 2.02.01-83 п. 2.27).
- Коэффициенты d_0 по типу грунта (глина/суглинок/супесь/песок).
- Снеговые зоны РК I–VI — укрупнённая классификация по годовому снегонакоплению.

## Запуск

python3 double_site_report.py 51.1605 71.4704            # markdown
python3 double_site_report.py 51.1605 71.4704 --json     # JSON 
Отчёт сохраняется в reports/site_YYYYMMDD_HHMMSS.md и печатается в консоль.
